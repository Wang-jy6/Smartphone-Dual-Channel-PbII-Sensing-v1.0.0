# Contributing

Please keep contributions reproducible and limited to one clear purpose per change.

- Preserve the original `.xlsx` workbooks and representative images.
- Put data cleaning or derived values in new files or columns and document the transformation.
- Update the canonical uni-app source in `04_Code/`; do not commit generated native output from `unpackage/`.
- Do not commit AppSecrets, tokens, personal project settings, generated `unpackage/` output, or private sample information.
- Document tested HBuilderX and WeChat Developer Tools versions when changing application code.
- Include units in data headers and use one observation per row in new analytical tables.
