# Representative raw images

This directory contains representative JPEG images for the 405 nm and 520 nm measurement conditions. Filenames identify the wavelength and, where applicable, the Pb(II) concentration or sample treatment.

Keep the original JPEGs unchanged. If an image is cropped, color-corrected, compressed, or annotated, save it as a new derived file and document the processing steps. Confirm that public release of every image is permitted and that embedded camera metadata is appropriate for publication.
