# Device design files

The `3D-printable files/` directory currently contains two native SolidWorks part files:

- Upper part of the device
- Lower-section assembly

These files preserve editable CAD geometry but are not directly portable to every slicer or CAD package. Before fabrication, confirm model units, dimensions, clearances, material, orientation, support strategy, layer height, infill, and printer tolerances in SolidWorks or an exported neutral format.

A future archival release should add:

- STL or 3MF files for printing
- STEP files for CAD interoperability
- an assembly drawing or labeled image
- validated material and print settings
- revision identifiers linking exported files to the SolidWorks sources
